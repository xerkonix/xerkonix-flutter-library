tokens.css --font lists "Noto Sans CJK KR" as the first legally loadable
fallback after Inter / system names. Flutter CanvasKit cannot paint those
system names (measured). This file is the official Korean subset VF of
that Noto CJK project — not an Inter CDN, not an extracted Apple face.

Flutter registers it as family "Noto Sans CJK KR" via FontLoader.
wght 400 / 450 / 550 use dart:ui FontVariation.weight (variable axis).
Static Regular/Medium cannot paint 450 or 550.
